# ASSET PIPELINE — MOSCOW LIFE
Реестр фактических ассетов — `ASSET_MANIFEST.md`. Здесь — правила. Агентам: skill `moscow-asset-pipeline`.

## Художественный стиль — «Premium cinematic 2.5D diorama»
Кадр атмосферного анимационного фильма о Москве: мягкий hand-painted рендер, выразительный свет с понятными источниками, глубина из 6–8 планов (foreground → characters → main env → secondary env → background architecture → atmosphere → lighting → weather), узнаваемые места, разные материалы (металл, стекло, ткань, дерево, камень, асфальт, кирпич, керамика). Не детская мультяшность, не flat, не фотоколлаж, не пластик. Палитра UI: ink `#1b1530`, dusk `#2a2150`, peach `#ffb27a`, rose `#f06a8f`, cream `#fff3e2`; без чистого чёрного/белого. Полный Style Guide — `.claude/skills/moscow-visual-art-direction/SKILL.md`.

### Слои локации (как устроено сейчас и куда встраивать растр)
| Слой | Сейчас (процедурно) | Если появится растр |
|---|---|---|
| Background (небо, дальняя архитектура) | `SkyLayer`, `Landmark`, back-план `SceneShell` | AVIF-план без текста, нейтральный свет; ночные окна — отдельная маска |
| Midground | mid-план, `Building`, деревья | спрайт-лист фасадов района |
| Foreground | fore-план (`fore-sway`) | PNG/WebP с альфой |
| Character sprites | `Person.tsx` (процедурные позы) | не планируется: анимация позами в SVG дешевле и стыкуется со светом |
| Environment props | `primitives`, `StreetKit`, `InteriorKit`, `Vehicles` | атлас пропсов |
| Weather effects | `WeatherRenderer` (canvas) | спрайты капель/снежинок (опц.) |
| Lighting effects | lights/bloom-планы + CSS-переменные | маски окон/витрин (alpha) |
| Animation assets | CSS keyframes (index.css) | — |

### Единые правила для любых изображений
- Ракурс и горизонт как у текущих сцен (холст 1600×900, база зданий y≈610, горизонт ≈ 560).
- Нейтральный полуденный свет без сильных теней — время суток, погоду и ночные окна добавляет LightingController.
- Без текста, вывесок с буквами, UI, людей (персонажи процедурные), логотипов и брендов.
- Серия делается за один раз по одному шаблону промпта и одному набору референсов (`ASSET_REQUESTS.md`).

## Приоритет источников
1. **Процедурный SVG** (по умолчанию): ноль лицензионных рисков, мгновенная загрузка, свет через CSS-переменные.
2. **Собственная генерация** (image-модель) — для живописных фонов, когда SVG не даёт нужной детализации.
3. **CC0 / CC-BY** — только с записью атрибуции.
Не используем: ассеты без явной лицензии, «free for personal use», копии чужих артов и фото достопримечательностей, стоковые фото.

## Требования к файлам
| Тип | Формат | Размер | Вес |
|---|---|---|---|
| Фон/иллюстрация плана | AVIF + WebP фолбэк | 1600 и 3200 px по ширине (под холст 1600×900) | ≤ 300 КБ @1600 |
| Спрайты/персонажи | атлас WebP/PNG + JSON | кратно 2, без лишних полей | ≤ 200 КБ на атлас |
| Иконки | SVG (lucide-react уже есть) | 24×24 сетка | — |
| Шрифты | WOFF2, OFL | subset кириллица + латиница | ≤ 60 КБ на начертание |
| Аудио (только если нельзя синтезировать) | OGG/Opus 96–128 kbps, 48 кГц | бесшовные лупы с нулевым пересечением | ≤ 500 КБ |
Растр — нейтрально освещённый полдень без сильных теней (свет добавляет LightingController); окна и фонари — отдельный слой-маска.

## Генерация изображений
- Один шаблон промпта на серию: «cozy lofi anime background, Moscow <место>, frontal view, soft pastel palette (#1b1530 #2a2150 #ffb27a #f06a8f #fff3e2), neutral midday light, no people, no text, flat soft shading, 16:9».
- Референсы: скриншоты текущих сцен (`node scripts/shots.mjs`) — новый ассет должен вставать рядом без шва по стилю.
- Рядом с исходником — `<name>.prompt.md`: модель, версия, seed, промпт, дата, условия лицензии сервиса.
- Генерируем сериями (все фоны одного района за раз), а не поштучно в разных стилях.
- Ключи генераторов — только на сервере/локально в `.env`, никогда в `VITE_*`. Стоимость сервиса оценить до использования.

## Хранение
```
assets/source/<category>/<name>.<ext>      — исходники (PSD/KRA/ASE/PNG 4K), не перезаписываются (хук), новая версия = name.v2.ext
assets/source/<category>/<name>.prompt.md  — промпт/лицензия
public/assets/<category>/<name>@1600.avif  — оптимизированные производные
```
Оптимизация: при появлении первого растрового ассета — добавить `sharp` (после проверки хуком) и скрипт `scripts/optimize-assets.mjs`; записать команду сюда.

## Лицензирование
Каждый внешний/сгенерированный файл → строка в `ASSET_MANIFEST.md`: файл, источник, автор, лицензия, ссылка, дата, атрибуция. Нет строки — файл не мержится.
