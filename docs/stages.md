## S7. Интерьеры и салоны
**Цель:** метро (вестибюль, платформа, вагон), автобус, такси, кафе, магазин, офис, дом — в 3D.
**Владельцы:** asset-pipeline-engineer, graphics-engineer, audio-engineer (акустические пространства уже есть — только сверка).
**Требует ассетов:** `ASSET_GENERATION_3D.md` §5.
**Готово, когда:** каждая не-уличная локация имеет 3D-сцену с ≥ 3 планами; постанционный проезд метро показан (табло, остановка, двери) (логика — `event.station` / `nextStation`); временное решение ниже снимается.

**До S7 (временное решение, без заглушек-пустышек).** Для не-уличных локаций World3D показывает реальный город: камера — внешний план здания/входа на якорной улице (`event.anchor`), герой не рисуется (он внутри), окна здания тёплые (эмиссия из `worldLight`), подпись и звук — как сейчас (акустическое пространство уже есть). Автобус/такси (`bus-ride`) — камера сопровождения транспортного инстанса по маршруту в 3D-городе (реальная геометрия). Метро (`metro-station`/`metro-ride`) — внешний план входа в вестибюль (павильон, вывеска) с затемнением кадра на время подземной части; подпись станции из `event.station`. От graphics-engineer нужно: режим камеры `exterior-shot` и `chase-cam` в `camera/` (чтение `worldStore.location`/`event`, без записи в сторы), маркер «внутри» (скрыть героя), emissive-окна в `worldLight`/здании, затемнение кадра как uniform. Ассеты не нужны (всё из запечённого района S2); если у якорной улицы нет запечённого района — шаг не начинается, список недостающего — пользователю.
