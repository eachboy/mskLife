# MOSCOW LIFE — Asset Pipeline

Сейчас весь визуал — процедурные SVG-компоненты (`src/scenes/art`), музыка — синтез Tone.js, внешних файлов нет (см. `docs/ASSET_MANIFEST.md`). Это осознанное преимущество: ноль лицензионных рисков, мгновенная загрузка, бесшовное освещение через CSS-переменные. Любой внешний ассет должен оправдать отказ от этих свойств.

## Решение «процедурно или файл»
Сначала попробуй процедурный SVG. Файл оправдан, только если нужна детализация, недостижимая в SVG без тысяч узлов (живописный фон, фототекстура), и он проходит правила ниже. Подробности и требования — `docs/ASSET_PIPELINE.md` в корне.

## Правила
1. **Лицензия до использования**: только собственная генерация, CC0, CC-BY (с атрибуцией) или OFL/MIT для шрифтов/иконок. Запиши источник, автора, лицензию, дату в `docs/ASSET_MANIFEST.md`. Нет понятной лицензии → не используем. Не копируем чужие арты/фото достопримечательностей.
2. **Исходники неприкосновенны**: оригинал → `assets/source/<category>/<name>.<ext>` (хук guard запрещает перезапись; новая версия = `name.v2.ext`). В `public/` — только оптимизированные производные.
3. **Форматы**: фон/иллюстрация — AVIF + WebP фолбэк, ширина 1600 и 3200 (2x), ≤ 300 КБ на 1600; спрайты — атлас PNG/WebP с JSON-картой; иконки — SVG (lucide-react уже есть); аудио — OGG/Opus 96–128 kbps, только для того, что нельзя синтезировать.
4. **Совместимость со светом**: растровые слои должны быть нейтрально освещены (полдень, без сильных теней), чтобы LightingController мог тонировать их CSS-переменными; ночные окна — отдельным слоем-маской.
5. **Стиль**: каждый ассет проходит skill `moscow-visual-art-direction` (палитра, перспектива, план).
6. **Генерация изображений**: используй единый промпт-шаблон и референсы из `docs/ASSET_PIPELINE.md` (стиль, палитра, ракурс, время суток = «нейтральный день»), фиксируй seed/модель/промпт рядом с исходником (`<name>.prompt.md`). Не генерируй объекты по одному в разных стилях — делай серии.
7. **Секреты генераторов** — только на сервере, не в `VITE_*`.

## Оптимизация
`sharp` в проект не добавлен (растра нет). Когда появится первый растровый ассет — добавь скрипт `scripts/optimize-assets.mjs` на sharp (после проверки зависимости хуком guard) и запиши команду в `docs/ASSET_PIPELINE.md`.
